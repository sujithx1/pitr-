Enterprise Disaster Recovery & Live Replication Engine

High-availability PostgreSQL 18 solution combining block-level delta backups via pgBackRest and sub-second transaction tracking using native Logical Decoding (test_decoding).

BACKUP ENGINE

Why pgBackRest?

Standard tools like pg_dump or pg_basebackup require wiping and copying entire multi-gigabyte databases from scratch. pgBackRest performs block-level delta restores, transferring only modified data blocks for 95% faster recovery!

# Multi-threaded Block-Level Delta Restore pgbackrest --stanza=db --delta restore
REAL-TIME STREAMING

Why Logical Decoding (`test_decoding`)?

Traditional WAL inspection via pg_waldump requires heavy text parsing and disk reading. test_decoding is built directly into core PostgreSQL, decoding binary WAL streams into JSON events instantly with zero disk read penalty.

SELECT * FROM pg_logical_slot_peek_changes( 'pitr_logical_slot', NULL, 500 );
AUTOMATION

Automated Backup Cron Pipeline

Base backups and WAL archiving are automated via Linux cron schedules. Full base backups run every Sunday at 2:00 AM, while incremental backups run Monday through Saturday at 2:00 AM.

# Install Automated Schedule ./scripts/install_cron.sh

Point-in-Time Recovery (PITR) Modes Comparison

Recovery Mode Port Downtime Description & Use Case Execution Script
Promoted Cluster Clone 5434 🟢 Zero Downtime Boots an independent database clone on Port 5434 without interrupting the live production app on Port 5433. Perfect for audit testing and historical queries. ./scripts/restore_cluster_clone.sh <LSN>
In-Place Recovery 5433 🔴 Requires short DB restart Overwrites the production database container directly up to the requested target LSN checkpoint. Automatically flushes active WAL logs (SELECT pg_switch_wal();) before restoring. ./scripts/restore_inplace.sh <LSN>
